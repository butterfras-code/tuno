# tuNotes Phase 5 validation

Implemented on `feature/tunotes-phase5`, based on local `t3code/create-note-reading-game` at `4908b18` (2026-09-27). This is an unmerged review candidate. The final automated build has tUno ID `da85a6660fcd1e0f` and tuNotes ID `37990815643764d9`; [release metadata](tunotes-stage5/release.json) marks the source tree dirty because the work was uncommitted when built.

## Behavior reviewed

The top selector is Practice / Challenge / Multi Player / Options. Solo Challenge and Practice remain separate. Multi Player accepts 1–8 local players, add/remove/reorder, names, one optional saved profile per player, and independent preset/adaptive choices. It reuses the existing picker, Custom configurator and Timed/Target rule form. Guest learning stays in memory by roster ID; saved profile observations and results use the existing bounded store. Retry creates new engines and Uno reward schedules while retaining those learning contexts.

Turns give each roster entry one full allocation. Pairs group adjacent players, with an odd final solo heat. Each heat has explicit Ready and a shared three-second count-in. Every active panel has its own Challenge engine, staff, answer controls, feedback, clock/target and Uno. A finished panel accepts no input while the partner continues. Left Q–U and right Z–M map A–G; held left 1/2/3 and right 8/9/0 select flat/natural/sharp. Pointer gestures stay with their panel. Shared pause and visibility loss preserve prompts and remaining time and unrank active runs. An active pair pauses when available content drops below 960 CSS pixels or viewport height below 600; the player can restore space and resume or explicitly restart as turns. Setup prevents starting pairs on a small view.

The scoreboard ranks only qualified results, compares unrounded Timed scores or integer-millisecond Target completion times, shares exact ties, and lists unranked participants in roster order. Duplicate names show a roster seat number. Early end shows not-yet-played players as unranked. Retry, Edit setup and Home are available. Teams, co-op, relay and Flow are still outside Phase 5.
